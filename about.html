03 / About

Phạm Thanh Tùng, Generalist 3D & Technical Artist.

3+ years building maps, shaders and tools for mobile MMORPGs and Nintendo Switch / PC / PS titles.

I'm a Generalist 3D Artist with a Technical Art lean, based in Hà Nội. My day-to-day is building scenes and maps that ship — blockout, set-dressing, lighting, and the optimization pass that makes them run on the target device.

I've worked on mobile MMORPGs as well as a handful of titles for Nintendo Switch, PC and PlayStation. My main engine is Unity (Built-in, URP, Shader Graph, Editor scripting) and I work in Unreal for console projects.

Alongside art, I write tools — Unity Editor utilities in C# and pipeline / DCC automation in Python (with Qt UIs) — to cut repeat work and keep our team's builds clean.

What I'm chasing right now: going deeper as a Technical Artist, raising visual quality without hurting frame budgets, and shortening the path from concept to a playable scene.

05 / Builds Tools / Scripts

Tools I've written for art teams.

Small Unity Editor utilities and Python pipeline scripts that pay for themselves in a sprint.

C#BatchAssetImporter.cs

Batch Asset Importer

Unity Editor window for art-team batch import / export with naming convention checks, FBX import preset routing, and a dry-run preview. Handles a few hundred meshes per pass.

●shipped · in daily use
C#AssetAuditWindow.cs

Asset Audit Tool

Editor scanner that walks a Resources folder and flags poly-count, texture size, draw call and memory budget violations against per-tier rules. Outputs a CSV report for producers.

●shipped · MMORPG mobile
C#PivotOriginReset.cs

Pivot & Origin Reset

Right-click context menu in the Project window — pick a vertex, the bottom-center, or the bounding box, and the script bakes a new pivot via a dummy parent transform.

●shipped · saves 20m / day
C#PreBuildValidator.cs

Pre-build Validator

Pre-build hook that runs before pushing to GitLab — checks LOD setup, collider presence, texture compression overrides, missing references, and breaks the build with a readable report if anything's off.

●shipped · CI gate
PYdcc_pipeline.py

DCC Automation (Python)

Maya / Blender side-scripts with PySide / Qt UIs — batch UV layout, retopo cleanup helpers, and an export-to-Unity wrapper that enforces our scale, axis and naming rules at source.

●internal · 2 studios
HLSLenv_shader_pack.shader

Environment Shader Pack

URP Shader Graph + HLSL hybrid: water with foam masks, height-fog, vertex foliage wind, and a generic dissolve with edge-glow. Tuned for mid-tier mobile (Adreno 6xx and up).
